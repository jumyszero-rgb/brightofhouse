1. プロジェクト概要
プロジェクト名: braightofhouse.jp
目的: 自社のホームページ　braightofhouse.jp　の作成
特徴: 自社のホームページながら、アドミンログインを有効にし、コードなしでブログ、LP、作業価格、ほかページを作成できる機能をもつ。

2. 技術スタックとインフラ
フロントエンド / API: Next.js 15.5.14 (App Router)
データベース: Supabase (PostgreSQL) + Prisma ORM
認証: API AUTH 認証　（メールへ6桁パスワードを送信し、入力することでログイン）
ストレージ: Cloudflare R2
エディタ: BlockNote + AI執筆

3. アーキテクチャとマルチカラム設計
このサイトに関してはカラムは必要なし。
